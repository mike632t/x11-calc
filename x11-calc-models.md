## Models

```
Model    Date  Description
HP-35    1972  The world's first pocket calculator with transcendental
               functions and RPN.
HP-80    1973  Designed for business it included functions for Mean and
               Standard Deviation Time Value Of Money, Sum of Digits
               amortisation, Least squares linear regression, Bond Price
               and Yield, Accrued Interest/Discounted Notes, Past or future
               dates and Days between dates.  First model with a shift key!
HP-45    1973  Improved version of the HP-35 with 9 memory registers, and
               ability to use radians or grads for trigonometric functions,
               as well as polar to rectangular conversions, some basic
               statistics functions, percent, delta percent, factorial etc
               First to support fixed and scientific display notation.
HP-46    1973  Desktop version of the HP45 with a built in printer.
HP-81    1973  Desktop version of the HP81 with a built in printer, twenty
               storage registers, log10, constant arithmetic and additional
               financial functions.
               First model to use the decimal key to select additional
               storage registers.
HP-65    1974  First programmable pocket calculator. Programs could be up
               to 100 steps in length and could be written to or read from
               magnetic strips.
HP-70    1974  A lower end business calculator designed to complement the
               HP-80. It retained the time value of money solver dropped,
               bond price and yield, sum of digits depreciation, summation
               and averaging, linear regression, day and date arithmetic etc.
HP-55    1975  Lower cost version of the HP-65 without a magnetic card
               reader and with only 49 program steps.  However, it had
               twenty storage registers and server additional built-in
               functions including linear regression and unit conversions.
               Only model with an accurate timer.

HP-21    1975  A smaller less expensive version of the HP-35 with support
               for radians, polar/rectangular conversions, and storage
               arithmetic (using separate keys).
HP-25    1975  Smaller programmable model with 49 program steps.
               First model with fully merged programming steps and an
               engineering display mode.
HP-22    1975  A replacement for the HP-70 it had ten storage registers (in
               addition to the financial registers) and a large number of
               additional functions including the ability to compute
               accumulated interest, remaining balance, square root, e^x,
               natural log, linear regression, linear estimate, arithmetic
               mean, and standard deviation.
HP-91    1976  First battery powered printing calculator, it used a thermal
               printer (low power/noise) and had all the features of the
               HP-46 plus six more registers (R.0-R.5), H.MS+ and H.MS-,
               linear regression, round up, percent and an engineering
               display mode.
HP-27    1976  First model to include trigonometric, statistical and
               business functions.
HP-25C   1976  An improved version of the HP-25 featuring low powered CMOS
               memory devices that were powered even when the calculator
               was switched off. (A capacitor inside the calculator made it
               possible to change the battery pack without losing the data
               stored in memory).
HP-67    1976  Introduced at the same time as the HP-97, these two models
               were functionally equivalent with fully merged keystrokes,
               224 program steps and 26 storage registers, three levels of
               subroutine, and indirect addressing.  Both programs and data
               could be stored on magnetic cards.
HP-97    1976  Desktop printing version of the HP-67.
HP-10    1977  A non RPN desktop adding machine with a thermal printer.
HP-29C   1977  An improved programmable calculator with 98 program steps,
               thirty storage registers, program labels, three levels of
               subroutine,  increment/decrement looping, and indirect
               addressing.
HP-19C   1977  Desktop printing version of the HP-29C.
HP-92    1977  A desktop business/financial model with a built-in thermal
               printer with 20 storage registers, plus the dedicated
               financial registers and 10 separate registers for summation.
               It also featured an improved Time Value of Money solver
               that could compute any of the basic five financial values
               given four known values, depreciation using declining
               balance, straight line, or sum-of-the-years-digits methods
               and accounted for book value and salvage value.
HP-95C         Prototype only
HP-97S   1977  An HP-97 with an additional external BCD I/O module.

HP-31E   1978  A replacement for the HP-21 having four registers, storage
               arithmetic, support for grads, degrees/radians conversion,
               basic US to metric unit conversions, last x, percent,
               mantissa display and a self test.
HP-32E   1978  A non programmable model with an an emphasis on statistics,
               this model included mean and standard deviation, linear
               regression, linear estimate, correlation coefficient, normal
               distribution, and inverse normal distribution, factorial,
               delta percent, hyperbolic trigonometric functions, and unit
               conversions.
HP-33E   1978  A replacement for the HP-25 with 49 program steps, eight
               storage registers, three levels of subroutine, linear
               regression, correlation coefficient and degrees/radians
               conversion.
HP-38E   1978  The first programmable business calculator, and the first to
               use shared memory for programs and storage registers, it
               also included amortisation, internal rate of return,
               discounted cash flow analysis and net present value.
HP-33C   1979  A version of the HP-33E with continuous memory.
HP-34C   1979  First model with integration, a solver for root finding and
               a gamma function. It had between 70 and 210 program steps,
               with label addressing and line number addressing using the
               index register, and up to 20 additional storage registers.
HP-37E         A replacement for the HP-22 with seven storage registers,
               standard deviation, linear regression, correlation
               coefficient, factorial, and reciprocal.
HP-38C   1979  A version of the HP-38E with continuous memory.

HP-41C   1979  The first model with an alpha-numeric display, and user
               definable key mappings, it has up to 63 storage registers,
               that were also used for program storage and four expansion
               ports that could hold additional memory, an HP-IL interface,
               pre-programmed ROMs, or magnetic card reader/writer.
               Installing memory modules in all 4 ports provided a maximum
               of 319 storage registers.
               The HP-IL interface allowed the calculator to be used with
               several different peripherals including thermal, ink-jet and
               impact printers, a tape drive, floppy disk drive, modem,
               and a serial interface as well as GPIO and HP-IB interface
               modules.
HP-41CV  1980  Included the four additional memory modules internally.
HP-41CX  1983  Added a clock, some additional functions and more memory.

HP-11C   1981  A mid range scientific programmable that was the first to
               include a built-in random number generator and a backspace
               key that allowed numbers to be corrected a digit at a time.
               It had between 63 and 203 program steps, with both label
               addressing and line number addressing using the index
               register, and up to 20 additional storage registers and four
               levels of subroutine, hyperbolic trigonometric functions,
               gamma function, combinations, permutations, and self test
               functions.
HP-12C   1981  The longest running and best selling model in the HP
               calculator product line.  In addition to the functions
               available on the HP-38C the HP-12C provides odd period
               calculations (allowing interest to accrue for some arbitrary
               amount of time before the first payment), bond calculations,
               and depreciation calculations.
HP-15C   1982  An advanced scientific programmable replacing the HP-34C, it
               had 67 storage registers and up to 448 program steps and
               added recall arithmetic, hyperbolic trigonometric functions,
               random number generator, combinations and permutations,
               matrix operations and support for complex numbers.
HP-16C   1982  A programmable calculator for programmers that could perform
               integer and floating point arithmetic, convert between
               decimal, binary, octal, and hexadecimal, with binary shift
               (arithmetic and non arithmetic) and rotate operations (with
               or without carry), and bitwise boolean operations (and, or,
               not, and xor) with enough storage for up to 203 program
               steps shared between programs and storage registers.
HP-10C   1982  An entry level model with a maximum of 10 storage registers
               or 79 program steps it had a similar set of features to the
               HP-31E but added continuous memory, programming with line
               number addressing, an engineering display format, mean,
               linear regression, linear estimate, and correlation
               coefficient.
```
